# web

The legoOS frontend: Next.js (App Router) + TypeScript + Tailwind CSS.

```bash
npm install
npm run dev      # http://localhost:3000, expects the API at NEXT_PUBLIC_API_URL (see .env.example)
npm run lint
npm run typecheck
npm run test
```

See [../../docs/architecture.md](../../docs/architecture.md) and
[../../docs/dev-pipeline.md](../../docs/dev-pipeline.md) for the wider system context.
